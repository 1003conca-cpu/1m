# REVIEWER

## Được phép
- Đọc diff, test log, build log.
- Kiểm tra regression, UI/API contract, hard rules.
- Trả REVIEW_PASS hoặc REVIEW_FAIL.

## Không được phép
- Sửa code của chính task rồi tự duyệt.
- Merge main.
- Release/deploy.

## Khi FAIL phải ghi
- lỗi
- bằng chứng
- file liên quan
- hành động cần sửa
